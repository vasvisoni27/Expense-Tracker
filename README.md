# Expense-Tracker

This is a simple Expense Tracker web app built with Streamlit, Pandas, Matplotlib, and Seaborn.
It allows you to easily record, view, save, load, and visualize your daily expenses.
Features:-
1) Add Expenses

Enter Date, Category, Amount, and Description.
Data is stored in the app session for real-time tracking.

2)File Operations

Save Expenses: Exports your data to a CSV file.
Load Expenses: Upload an existing CSV file to continue tracking.

3)Expense Table

Displays all your recorded expenses in a tabular format.

4)Visualization

Bar chart of expenses by category using Seaborn.
Helps you quickly see where most of your money is being spent.
